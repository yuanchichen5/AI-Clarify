## 一、测试环境与前置条件

| 项 | 要求 |
|----|------|
| Node.js | ≥ 18（实测 Node v24.18.0） |
| 浏览器 | Chrome / Edge 最近两个大版本 |
| 运行命令 | `npm run dev`（开发）/ `npm run build && npm start`（生产） |
| AI 密钥 | 有密钥 → 真实解析；无密钥 + `MOCK_AI=true` → 演示解析（明确标注） |
| Supabase | 已配置 → 云存储归档；未配置 → 演示模式本地存储归档 |

## 二、M1-1 统一 AI 抽象层

| 编号 | 优先级 | 用例 | 步骤 | 预期 |

## 四、M1-3 解析 API 与异步任务

| 编号 | 优先级 | 用例 | 步骤 | 预期 |
|------|--------|------|------|------|
| M1-TC-030 | P0 | 提交解析 | POST /api/parse {mode,text} | 200，返回 `{data:{jobId}}` |
| M1-TC-031 | P0 | 任务轮询 | 每 2s GET /api/jobs/:jobId | pending→running→done，终态后返回结构化结果 |
| M1-TC-032 | P0 | 任务失败 | 触发解析异常 | status=failed + error 可读信息，前端提示且不丢用户输入 |
| M1-TC-033 | P0 | 未知任务 | GET 不存在的 jobId | 404 `NOT_FOUND` |
| M1-TC-034 | P0 | 参数校验 | 缺 mode 提交 | 400 `BAD_REQUEST` |
| M1-TC-035 | P0 | 超长文本容错 | 提交 15 万字符 | 服务端正常返回 jobId（前端已限 10 万） |
| M1-TC-036 | P1 | 图片解析 | 上传图片走解析 | 进入视觉解析路径（Qwen-VL），返回结构化结果 |
| M1-TC-037 | P1 | 学科推断兜底 | 置信度 < 0.6 的文本解析 | 前端弹出学科选择弹窗，选择后带 subject 重新提交 |
