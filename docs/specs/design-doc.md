---

## 一、设计原则

| 原则 | 说明 |
|------|------|
| 简洁优先 | 所有界面以知识内容为核心，剔除装饰性元素，降低认知负荷，让用户专注于整理与复习。 |
| 速度至上 | 录入、生成、检索全链路压缩操作步骤，交互轻量化，匹配产品性能指标要求。 |
| 够用即可 | MVP 阶段仅保留核心功能入口，不堆砌冗余选项，后续迭代按需扩展。 |
| 视觉降噪 | 通过留白与细边框实现层级区分，无多余阴影与渐变，突出结构化知识本身。 |
| 容错友好 | AI 生成结果支持全量编辑，异常场景提供清晰兜底路径，不丢失用户已输入内容。 |

## 二、风格与设计 Token

整体风格为**极简冷调紫白风格，无阴影设计**，完全依靠留白加细边框实现视觉分层。

### 配色系统

| Token | 色值 | 用途 |
|-------|------|------|
| 品牌主色 | `#7C6AED` | 主按钮、激活状态、重点知识点标识、高亮边框 |
| 页面背景 | `#F8F7FC` | 全局页面底色、侧边栏底色 |
| 卡片背景 | `#FFFFFF` | 内容卡片、输入框、弹窗、消息气泡 |
| 边框分隔色 | `#E8E6F2` | 所有分隔线、卡片边框、输入框边框、未激活状态 |
| 一级文字 | `#2B2A35` | 页面标题、正文核心内容、知识点标题 |
| 二级文字 | `#6B6A78` | 辅助说明、次要信息、时间戳、标签说明 |
| 三级文字 | `#A09FB0` | 置灰提示、占位符、非激活导航、折叠内容 |
| 成功色 | `#3CC28A` | 答对、已掌握、完成状态、解析区标识 |
| 警告色 | `#F5A524` | 提醒、超限、难点内容标识、待确认 |
| 错误色 | `#F87171` | 失败、答错、薄弱知识点、错误提示 |

### 内容标识（知识点条目左边框）

| 标识 | 左边框色 | 场景 |
|------|----------|------|
| 重点 | `#7C6AED` | 标记重点知识点条目 |
| 难点 | `#F5A524` | 标记难点与补充内容条目 |
| 冗余 | `#A09FB0` | 标记段子、非核心内容，默认折叠 |

### 目录与标签色系（8 种）

紫罗兰、天青、松绿、琥珀、樱粉、靛蓝、灰蓝、浅灰，均为低饱和冷调，用于目录分类、标签标记。

> 说明：上述 8 种目录/标签颜色在本规范中仅定义色相名称，具体 HEX 值待开发时按"低饱和冷调"原则统一取值并与主色体系协调。

## 三、布局模式

全局统一采用**顶部通栏 Header + 主体内容区 + 底部 Footer** 的基础框架，主体区域按场景分为双栏与单栏两类，所有页面视觉结构保持一致。

| 页面 | 布局 | 说明 |
|------|------|------|
| 笔记知识库主页（核心首页） | 双栏 | 左侧目录与笔记列表固定 280px，右侧笔记详情/编辑/思维导图内容区占满剩余宽度 |
| AI 对话助手页 | 双栏 | 左侧历史会话列表固定 260px，右侧对话流式展示区 + 底部输入框 |
| 多模态录入页 | 单栏居中 | 内容最大宽度 `max-w-4xl`，垂直居中对齐 |
| 复习中心页 | 单栏流程式 | 内容最大宽度 `max-w-3xl`，分三阶段：选择复习模式、知识点回顾/逐题作答、批改结果展示 |
| 数据看板页 | 单栏网格 | PC 端 2 列等宽网格，承载趋势图、知识图谱、数据卡片 |
| 帮助中心页 | 双栏 | 左侧帮助文档导航固定 220px，右侧文档内容展示区 |

## 四、逐页文字布局

所有页面遵循 **Header → 主体内容 → Footer** 的从上到下结构。

### 通用组件

**通用 Header**：左侧产品 Logo 加名称，中间全局搜索框，右侧「新建笔记」主按钮加用户头像。

**通用 Footer**：左侧版权信息，右侧「帮助中心」「反馈」入口，内容不足时贴底显示。

---

### 1. 笔记知识库主页（双栏）

**左侧边栏（次内容 + 导航操作）**

- 顶部：新建笔记主按钮 + 下拉箭头，展开可选择 7 种录入方式。
- 中部：目录树列表，支持展开折叠，当前目录高亮，悬停显示新增、重命名、删除操作。
- 下部：当前目录下的笔记列表，按更新时间倒序，每条显示标题、学科标签、更新时间。
- 底部：用户信息栏，包含头像 + 昵称。

**右侧主内容区（主内容 + 编辑操作）**

- 顶部操作栏：面包屑导航、视图切换（笔记视图 / 思维导图视图）、筛选（学科、标签）、导出按钮、归档按钮。
- 笔记视图内容区：可编辑笔记标题、学科标签、知识点分层列表；重点条目带紫色左边框，难点条目带琥珀色左边框，支持折叠展开；另含难点标注区、补充材料区。
- 思维导图视图内容区：居中展示思维导图画布，支持缩放、拖拽，节点样式区分重点、难点。
- 底部编辑栏：自动保存状态提示 + 版本历史入口。

---

### 2. 多模态录入页（单栏居中）

页面标题为「新建录入」。

- 顶部 Tab 栏：7 种录入方式切换（拍照、截图、文本、对话、PPT、PDF、视频），默认选中上次使用方式。
- 中部主操作区：文件拖拽上传热区，虚线边框，支持点击选择文件，下方标注支持的格式与大小限制；文本、对话模式下替换为多行输入框。
- 下部上传队列列表：每条显示文件名、进度条、状态（上传中、解析中、成功、失败），失败项显示重试、删除按钮。
- 底部：开始解析主按钮，全部文件上传完成后激活。

---

### 3. AI 对话助手页（双栏）

**左侧边栏（次内容 + 会话管理）**

- 顶部：新建对话按钮。
- 中部：历史会话列表，按时间倒序，每条显示会话标题、最后消息时间，当前会话高亮。
- 底部：清空历史入口。

**右侧主内容区（主内容 + 交互）**

- 顶部：当前会话标题 + 整理为笔记按钮。
- 中部对话消息流：用户消息靠右浅紫背景，AI 消息靠左白色背景；支持流式逐字输出，知识点与代码块自动高亮。
- 底部：多行输入框 + 附件上传按钮 + 发送按钮，支持 `Ctrl+Enter` 快捷发送。

---

### 4. 复习中心页（单栏流程式）

**阶段一：选择复习模式**

- 页面标题为「复习中心」。
- 主体三个模式卡片横向排列：每日复习、周度复盘、考前突击，每张卡片显示适用场景与说明。
- 底部：学科选择下拉框 + 开始复习主按钮。

**阶段二：逐题作答、知识点回顾**

- 顶部：进度条（第几题 / 共几题）+ 退出按钮。
- 中部：题干区（知识点卡片或变体题题目）+ 答题区（输入框或选项）。
- 底部：上一题、下一题、提交交卷按钮。

**阶段三：批改结果**

- 顶部总览区：正确率数值、掌握度评级、薄弱知识点数量。
- 中部逐题详情：答对题目带绿色边框 + 正确标识，答错题目带红色边框 + 错误标识；每题区分题干区、用户作答、AI 解析区，解析区带绿色左边框。
- 底部：重新练习、返回复习中心、加入薄弱知识点按钮。

---

### 5. 数据看板页（单栏网格）

页面标题为「学习数据」。

- 顶部操作栏：时间范围切换（7 日、30 日、全部）+ 学科筛选。
- 主体 2 列网格卡片：
  - 左上方：学习趋势折线图，展示新增笔记数、复习完成率。
  - 右上方：知识掌握度环形图。
  - 左下方：薄弱知识点排序列表。
  - 右下方：知识图谱可视化。
- 每张卡片独立带标题与数据内容。

---

### 6. 帮助中心页（双栏）

- 左侧边栏：帮助文档分类导航，当前分类高亮。
- 右侧主内容区：文档标题、正文内容，右侧有悬浮目录锚点。

## 五、交互说明

### 基础交互

| 交互 | 规则 |
|------|------|
| 点击跳转 | 所有按钮、导航项、列表项点击跳转对应页面，主按钮点击带 0.1s 缩放反馈 |
| 展开折叠 | 目录树、知识点条目、解析内容支持点击标题平滑展开、折叠 |
| Hover 反馈 | 可点击元素悬停时，边框色从 `#E8E6F2` 加深为 `#C8C3E0`，背景色轻微加深，无阴影变化 |
| 选中状态 | 激活的导航、目录、会话使用主紫色左边框或浅紫背景标识 |

### 特殊交互

| 交互 | 规则 |
|------|------|
| 标签颜色选择 | 点击颜色选择器弹出气泡浮层，Teleport 定位，8 色圆形色块横向排列，点击即选即生效 |
| 拖拽上传 | 文件拖拽至录入热区时，热区边框变实色主紫、背景加深，松开鼠标立即开始上传 |
| 快捷粘贴 | 录入页全局支持 `Ctrl+V` 粘贴截图、文本，自动识别内容类型并进入对应解析流程 |
| AI 流式输出 | 笔记生成、对话回答均逐字流式输出，末尾带闪烁光标提示生成中，完成后显示操作按钮 |
| 无限滚动 | 笔记列表、会话列表滚动到底部自动加载下一页，显示骨架屏占位 |
| 思维导图交互 | 滚轮缩放、拖拽平移、点击节点展开折叠子节点、双击节点直接编辑文字 |
| 批量操作 | 笔记列表支持多选，批量执行归档、移动目录、导出操作 |

## 六、页面跳转

### 核心流程文字描述

- **笔记整理主流程**：知识库主页点击新建录入 → 录入页上传文件/输入内容并解析 → 笔记编辑整理页 → 修改确认后点击归档 → 返回知识库主页并展示新笔记。
- **复习巩固流程**：知识库主页进入复习中心 → 选择复习模式与学科 → 答题或知识点回顾页 → 完成作答进入批改结果页 → 重新练习或返回知识库主页。
- **AI 对话流程**：顶部导航进入 AI 对话助手页 → 发起对话 → 优质回答一键整理为笔记 → 归档至知识库对应目录。
- **数据查看流程**：顶部导航进入数据看板页 → 查看学习趋势与知识图谱 → 点击薄弱知识点跳转对应笔记或直接发起复习。
- **帮助流程**：页脚进入帮助中心 → 查阅功能说明与操作指南。

### 页面跳转关系

| 源页面 | 可跳转目标 |
|--------|-----------|
| 知识库主页 | 多模态录入页、复习中心页、AI 对话助手页、数据看板页、帮助中心页 |
| 多模态录入页 | 笔记编辑整理页（归档后返回知识库主页） |
| 复习中心页 | 复习作答页 → 批改结果页 → 知识库主页 / 复习作答页 |
| AI 对话助手页 | 笔记编辑整理页（对话内容整理为笔记） |
| 数据看板页 | 复习中心页（针对薄弱知识点发起复习） |

## 七、异常处理

### 空状态

| 场景 | 表现 |
|------|------|
| 首次使用无笔记 | 居中书本图标，主标题「开始你的第一份笔记」，副标题「支持拍照、PDF、视频等 7 种方式录入」，下方三个核心入口按钮：图片录入、文本录入、视频录入 |
| 目录为空 | 右侧内容区居中提示图标，文字「该目录下暂无笔记」，搭配立即录入按钮，下方展示 7 种录入方式快捷入口 |
| 对话历史为空 | 右侧对话区展示对话图标，文字「开启一次新对话」，输入框自动聚焦 |
| 看板无数据 | 各模块展示占位图标，文字「暂无学习数据」，搭配「去录入第一篇笔记」跳转按钮 |
| 搜索无结果 | 列表区展示放大镜图标，文字「未找到匹配的笔记」，附「建议更换关键词」提示文字 |

### 加载中

| 场景 | 表现 |
|------|------|
| 列表加载 | 笔记列表、会话列表使用骨架屏，每行含标题占位条、次要信息占位条，与真实条目高度一致 |
| AI 生成中 | 笔记整理、对话回答逐字流式输出，未生成区域显示淡灰占位，末尾带闪烁光标 |
| 文件处理中 | 上传队列显示进度条，解析阶段显示「AI 解析中」状态文字 |
| 图表加载 | 数据看板图表使用骨架屏占位，保持卡片尺寸不变 |
| 页面跳转 | 首屏加载显示顶部细进度条，不使用全屏加载动画 |

### 错误提示

| 场景 | 表现 |
|------|------|
| 网络断开 | 页面顶部红色固定提示条，「网络连接已断开，请检查网络」，恢复后自动消失 |
| 文件校验失败 | 上传前拦截，文件队列对应项标红，显示具体原因（格式不支持、大小超限、页数超限），提供删除、更换按钮 |
| 解析失败 | 对应文件项标红，显示「解析失败」，附重试按钮，不丢失已上传文件 |
| 大模型调用失败/限流 | 生成区域显示黄色提示框，「AI 服务暂时繁忙」，提供重试按钮，已生成内容完整保留 |
| 导出失败 | 轻量提示，「导出失败，请重试」，不跳转页面 |
| 鉴权失效 | 跳转登录页，自动保留当前编辑内容，登录后自动恢复 |

## 九、响应式断点规则

### PC 端（宽度 ≥ 1200px）

- 完整双栏布局，侧边栏固定宽度，主内容区自适应。
- Header 导航项完整展示。
- 数据看板保持 2 列网格布局。

### 平板端（宽度 768px ~ 1199px）

- 侧边栏默认收起为图标栏，点击展开抽屉式侧边栏，覆盖在内容区上方。
- 主内容区占满屏幕宽度。
- 数据看板变为 1 列堆叠布局。
- 录入页宽度自适应屏幕尺寸。

### 移动端（宽度 < 768px）

- 单栏布局，所有双栏页面的侧边栏改为底部抽屉，通过汉堡按钮唤出。
- 底部 Tab 栏替代顶部部分导航，包含知识库、录入、复习、我的四个入口。
- 数据看板单列展示。
- 录入页全宽展示，按钮与输入框尺寸放大适配触控操作。
- 思维导图默认缩放至适配屏幕宽度，支持双指缩放。
